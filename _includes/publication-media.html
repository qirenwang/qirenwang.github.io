{%- comment -%} Finds a paper's figures and videos by folder convention, so adding media needs no front-matter edits. Usage: {% include publication-media.html pub=page %} Folder: images/publications// where is the last part of the paper's permalink, e.g. /publications/vecbench/ -> vecbench Files: teaser.(png|jpg|jpeg|webp|gif) card image on the Publications list detail-1.png, detail-2.mp4, ... images or videos on the detail page, shown in file-name order Sets, for the caller: pub_teaser site-relative URL of the card image, or "" if none (a front-matter `teaser:` path, relative to /images/, wins) pub_media array of detail-* static files, in name order {%- endcomment -%} {%- assign pub_slug = include.pub.url | split: "/" | last -%} {%- assign pub_dir = "/images/publications/" | append: pub_slug | append: "/" -%} {%- assign pub_files = site.static_files | where_exp: "f", "f.path contains pub_dir" | sort: "path" -%} {%- assign pub_teaser = "" -%} {%- if include.pub.teaser and include.pub.teaser != "" -%} {%- assign pub_teaser = "/images/" | append: include.pub.teaser -%} {%- else -%} {%- assign pub_teaser_file = pub_files | where: "basename", "teaser" | first -%} {%- if pub_teaser_file -%} {%- assign pub_teaser = pub_teaser_file.path -%} {%- endif -%} {%- endif -%} {%- assign pub_media = pub_files | where_exp: "f", "f.basename contains 'detail-'" -%}
